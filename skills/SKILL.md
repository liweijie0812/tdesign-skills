# TDesign Skills

本仓库提供 14 个 TDesign skills，覆盖 Web、移动端、小程序和 uni-app 的组件使用、选型、页面搭配、设计规范、图标、文档和变更日志查询。

## 技能列表

| Skill | 用途 |
| --- | --- |
| `tdesign-skills` | 总入口：识别 TDesign 依赖、技术栈和任务类型，并路由到专项 skill。 |
| `tdesign-docs` | 文档入口：查询资料位置、组件覆盖矩阵、上游来源和跨端共享契约。 |
| `tdesign-usage-guide` | 使用指南：处理组件选型、相似组件比较、反模式、迁移和降级策略。 |
| `tdesign-composition` | 组件搭配：处理页面骨架、场景组合和 starter 页面模式。 |
| `tdesign-design-spec` | 设计规范：处理视觉规则、Design Token、色彩、布局框架、质量门禁和 DS 自检。 |
| `tdesign-icons` | 图标检索：查询图标名称、关键词、分类、包名、安装命令和导入方式。 |
| `tdesign-changelog` | 变更日志：按技术栈、组件、版本、关键词查询新增、修复、废弃和 Breaking Changes。 |
| `tdesign-react` | React Web：查询 `tdesign-react` 组件 API、props、事件、子组件和 JSX 写法。 |
| `tdesign-vue-next` | Vue 3 Web：查询 `tdesign-vue-next` 组件 API、props、事件、插槽和 `v-model` 写法。 |
| `tdesign-vue2` | Vue 2 Web：查询 `tdesign-vue` 组件 API、Options API、事件和插槽写法。 |
| `tdesign-mobile-react` | Mobile React：查询 `tdesign-mobile-react` 移动端组件 API 和 React 写法。 |
| `tdesign-mobile-vue` | Mobile Vue：查询 `tdesign-mobile-vue` 移动端组件 API、事件和 `v-model` 写法。 |
| `tdesign-miniprogram` | 小程序：查询 `tdesign-miniprogram` 组件 API、WXML、`bind` 事件和 `usingComponents` 写法。 |
| `tdesign-uniapp` | uni-app：查询 `tdesign-uniapp` 组件 API、easycom、`@event` 和 `v-model:value` 写法。 |

## 安装

GitHub：

```bash
npx skills add liweijie0812/tdesign-skills
```

国内镜像：

```bash
npx skills add https://cnb.cool/liweijie0812/tdesign-skills.git
```

安装后请重启对应工具，使新增 skills 生效。
