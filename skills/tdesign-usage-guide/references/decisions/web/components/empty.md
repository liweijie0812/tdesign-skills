# Web Empty 何时使用

本文描述 Web 场景下 `Empty` 的设计选型。具体 props、事件、插槽、子组件和类型必须回到当前技术栈 API 确认。

## 何时使用

- 当没有数据、没有结果或没有可展示内容时使用。
- 如果用户可以创建、重置或重试，应搭配恢复动作。

## 选型要点

- 先区分无数据、无搜索结果、筛选无匹配、无权限和加载失败；只有无可展示内容时使用 `Empty`。
- 文案应说明为什么为空，并给出下一步，例如创建、重置筛选、刷新或返回。
- 列表、表格、卡片区块都可以有局部空状态，不必整页替换。
- 流程成功、失败或异常结果应使用 `Result` 或页面结果表达，不要混用 Empty。

## 相关取舍

- 相似组件取舍见 `../similar-components.md`，优先按当前平台和当前技术栈确认。
- 常见相关组件：`Result`、`Skeleton`、`Button`。

## 反模式

- 不要只展示空图不说明原因和下一步。
- 不要用 `Empty` 掩盖错误、权限不足或加载中状态。
- 不要在同一页面堆叠多个大面积空状态，局部区域应轻量表达。
- 不要手写空插画和按钮重复实现 TDesign Empty 已有能力。
