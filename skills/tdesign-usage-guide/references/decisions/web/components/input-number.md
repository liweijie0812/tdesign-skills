# Web InputNumber 何时使用

本文描述 Web 场景下 `InputNumber` 的设计选型。具体 props、事件、插槽、子组件和类型必须回到当前技术栈 API 确认。

## 何时使用

- 当输入值必须是数字时使用。
- 当需要最小值、最大值、精度、步进或加减控制时使用。
- 适合数量、金额、比例、阈值、排序权重、库存、次数等数值字段。
- 当用户主要通过拖动选择近似值时，可考虑 `Slider`。

## 选型要点

- 先确认值是可计算的数字，而不是编号、手机号、银行卡号或带前导零的字符串。
- 需要单位、前后缀或相关控件时，可结合 `InputAdornment` 或表单说明。
- 精度、步进、范围、格式化和空值处理必须按当前技术栈 API 确认。
- 在表格或密集表单中使用时，要控制宽度和加减按钮密度。

## 反模式

- 不要用 `InputNumber` 输入手机号、身份证、邮编、账号等数字形态字符串。
- 不要只用普通 `Input` 接收需要范围、精度或步进约束的数值。
- 不要伪造单位和范围，应在字段标签、后缀或提示中明确表达。
- 不要把 Mobile `Stepper` 的触控用法直接套到 Web。
