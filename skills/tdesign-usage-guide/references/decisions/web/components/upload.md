# Web Upload 何时使用

本文描述 Web 场景下 `Upload` 的设计选型。具体 props、事件、插槽、子组件和类型必须回到当前技术栈 API 确认。

## 何时使用

- 当用户需要上传文件或图片时使用。
- 根据文件类型和任务密度选择列表、卡片或拖拽样式。

## 选型要点

- 先确认上传对象：单图、多图、普通文件、批量文件、拖拽上传或导入任务。
- 图片上传通常需要预览、删除和失败重试；文件上传通常需要文件名、大小、状态和进度。
- 大文件、批量上传、手动上传、自动上传、校验和自定义请求能力必须查当前栈 API。
- 上传后的处理结果可用 `Message`、`Alert`、`Table` 或业务状态表达，不要只停留在上传控件内。

## 相关取舍

- 相似组件取舍见 `../similar-components.md`，优先按当前平台和当前技术栈确认。
- 常见相关组件：`Progress`、`Loading`、`Message`。

## 反模式

- 不要用原生文件输入或其他库重复实现 TDesign Upload 已有能力。
- 不要省略文件类型、大小、数量、失败原因和重试路径。
- 不要把上传中、上传成功和业务处理成功混为一谈。
- 不要直接套用 Mobile 或小程序上传 API 到 Web。
