# Web Checkbox 何时使用

本文描述 Web 场景下 `Checkbox` 的设计选型。具体 props、事件、插槽、子组件和类型必须回到当前技术栈 API 确认。

## 何时使用

- 用于多选或相互独立的布尔选项。
- 当多个选项可以独立选择时使用。
- 只能选择一个选项时，优先使用 `Radio`。
- 需要即时切换开关状态时，优先使用 `Switch`。

## 选型要点

- 多个选项之间应相互独立，用户可以选择零个、一个或多个。
- 单个 Checkbox 适合协议确认、附加条件、延迟提交的布尔字段。
- 选项需要随表单一起提交时使用 `Checkbox`；切换后立即生效时使用 `Switch`。
- 选项很多或需要搜索、分组、穿梭选择时，考虑 `Select` 多选、`Transfer` 或业务封装。

## 反模式

- 不要用 `Checkbox` 表达只能选一个的互斥选项。
- 不要用 `Checkbox` 伪装开关，尤其是立即影响线上状态的操作。
- 不要把关键协议或风险确认默认勾选。
- 不要手写勾选框绕开 TDesign Checkbox 的半选、禁用和校验能力。
