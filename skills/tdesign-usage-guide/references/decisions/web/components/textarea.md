# Web Textarea 何时使用

本文描述 Web 场景下 `Textarea` 的设计选型。具体 props、事件、插槽、子组件和类型必须回到当前技术栈 API 确认。

## 何时使用

- 用于多行自由文本输入。
- 适合描述、评论、备注、长文本等场景。
- 短单行值使用 `Input`。

## 选型要点

- 输入内容应允许换行或长度明显超过单行，例如描述、备注、原因、评论、审批意见。
- 需要字数限制、自动高度、清空、禁用或校验状态时，必须查当前技术栈 API。
- 值需要随其他字段一起提交时通常放入 `Form`，并在字段附近展示校验反馈。
- 短名称、编号、手机号、邮箱、关键词等单行值使用 `Input`。

## 反模式

- 不要用 `Textarea` 承担富文本编辑、Markdown 编辑或复杂排版输入。
- 不要把短字段统一做成多行输入，避免表单密度失控。
- 不要只依赖 placeholder 说明格式、限制或示例。
- 不要手写 `textarea` 样式绕开 TDesign Textarea 的状态、尺寸和校验能力。
