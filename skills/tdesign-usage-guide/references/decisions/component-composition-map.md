# TDesign 组件搭配索引

本文仅保留入口索引。页面级组合、场景默认方案和设计细节统一转到 `tdesign-composition`。

## 查阅顺序

1. 先识别平台和技术栈。
2. 组件覆盖查 `skills/tdesign-docs/references/meta/stack-matrix.json`。
3. 页面怎么搭查 `skills/tdesign-composition/references/scenarios/README.md`。
4. Web 中后台细节查 `skills/tdesign-composition/references/reading-guide.md`。
5. Mobile / Miniprogram 页面查 `skills/tdesign-composition/references/scenarios/mobile-pages.md`。

## 边界

- 这里只回答“先去哪里查”。
- 组合方案和页面结构不在这里展开。
- 具体 props、事件、插槽和导入方式回当前技术栈 API skill。
- 组件不存在时，先回 `fallback-policy.md` 再决定降级。
