# Mobile Skeleton 何时使用

本文描述 `tdesign-mobile-react`、`tdesign-mobile-vue`、`tdesign-miniprogram` 和 `tdesign-uniapp` 中 `Skeleton` 的设计选型。具体 props、事件、插槽、external classes 和平台能力必须回到当前栈 API 确认。

## 何时使用

- 用于内容结构已知但数据未返回时的占位。
- 适合列表、卡片、详情等页面加载，避免空白等待。
- 当用户能预期即将出现的页面结构，且加载时间可能明显感知时使用。
- 不确定内容结构或只是按钮提交等待时，优先使用 `Loading`。

## 选型要点

- 骨架应贴近真实移动端结构，例如头像加文本、卡片块、列表行、详情字段。
- 首屏骨架可以稳定布局，减少接口返回后的跳动。
- 数据返回为空时切换到 `Empty`，失败时切换到错误提示或重试状态。
- 小程序和 UniApp 的动画、尺寸和样式覆盖能力必须查当前栈 API。

## 反模式

- 不要用 Skeleton 表达空数据、无权限或错误。
- 不要为极短加载强行加骨架，避免闪烁。
- 不要复刻过于复杂的真实页面，骨架只需表达结构预期。
- 不要手写灰块动画重复实现 TDesign Skeleton。
