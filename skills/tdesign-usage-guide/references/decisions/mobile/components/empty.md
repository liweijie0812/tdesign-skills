# Mobile Empty 何时使用

本文描述 `tdesign-mobile-react`、`tdesign-mobile-vue`、`tdesign-miniprogram` 和 `tdesign-uniapp` 中 `Empty` 的设计选型。具体 props、事件、插槽、external classes 和平台能力必须回到当前栈 API 确认。

## 何时使用

- 用于列表、搜索结果或页面无数据状态。
- 应给出下一步建议或可恢复动作，避免只展示空图。

## 选型要点

- 先区分无数据、无搜索结果、筛选无匹配、无权限、网络错误和加载中；只有无可展示内容时使用 `Empty`。
- 移动端空状态文案要短，并给出可触达动作，例如刷新、重置筛选、去创建、返回首页。
- 列表局部为空时放在列表区域内，避免整页空状态遮挡导航和操作。
- 流程成功、失败、异常或任务完成使用 `Result`，不要用 `Empty` 表达流程结果。

## 相关取舍

- 相似组件取舍见 `../similar-components.md`，优先按当前平台和当前技术栈确认。
- 常见相关组件：`Result`、`Skeleton`、`Button`。

## 反模式

- 不要只展示空图，不给原因和下一步。
- 不要用 `Empty` 代替错误页、无权限页或加载状态。
- 不要在同一移动页面堆叠多个大空状态，局部区域应轻量处理。
- 不要手写空状态插画和按钮重复实现 TDesign Empty。
