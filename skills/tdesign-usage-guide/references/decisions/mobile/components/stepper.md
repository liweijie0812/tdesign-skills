# Mobile Stepper 何时使用

本文描述 `tdesign-mobile-react`、`tdesign-mobile-vue`、`tdesign-miniprogram` 和 `tdesign-uniapp` 中 `Stepper` 的设计选型。具体 props、事件、插槽、external classes 和平台能力必须回到当前栈 API 确认。

## 何时使用

- 用于移动端数量加减。
- 适合商品数量、人数、份数等小范围数值调整。
- 适合用户需要通过加减按钮精确调整整数或小范围数值的场景。
- 连续范围近似选择使用 `Slider`；任意数字输入或复杂精度使用表单输入能力。

## 选型要点

- 数值范围、最小值、最大值、步进、禁用和输入能力必须按当前栈 API 确认。
- 加减按钮应足够易触达，常用于购物车、票数、人数、份数等高频触控场景。
- 变更会影响价格、库存或库存校验时，要及时反馈限制原因。
- 需要直接输入大数字或小数时，确认当前栈 Stepper 是否适合，否则使用表单输入。

## 反模式

- 不要用 `Stepper` 输入手机号、编号、金额备注等非数量值。
- 不要在大范围或需要搜索定位的数值场景强行使用加减按钮。
- 不要省略最小/最大限制和不可操作原因。
- 不要手写加减按钮重复实现 TDesign Stepper。
