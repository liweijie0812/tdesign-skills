## 说明

- TDesign 设计文档是产品设计选型的主要依据。
- `tdesign-common/js/components.ts` 是 Web 与移动端组件范围的主要依据。
- TDesign 框架文档是 API、props、事件、插槽和组件能力的主要依据。
- 通用企业级 UI 经验只作为补充判断，不作为 TDesign API 依据。
